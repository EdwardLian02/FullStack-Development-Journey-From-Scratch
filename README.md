# FullStack-Development-Journey-From-Scratch

A personal learning repository for rebuilding my **full-stack development foundations from scratch**.

## 🎯 Purpose

I created this repository because I realized that I have been integrating AI in my development process due to job requirement to fasten the development process. But after around 6 months of using complete AI. I am getting bored of coding even simple stuff. I realized this is not how it should be going. I pursue this path just because I like to build things brick-by-brick. So this is just a repo I created to refresh my foundation knowledge from the beginning by doing all the simple and basic works again. May be this should bring back where I come from :)

I know AI is an incredibly powerful tool, but I don't want to become a developer who can build things only by prompting AI. I want to understand **what I am building, why it works, and how to build it myself**.

The purpose of this repository is to slow down, go back to the fundamentals, and strengthen the knowledge that everything else is built upon.

> **The goal is not to avoid AI. The goal is to become capable without depending on it.**

## 🏗️ Learning Philosophy

This is not intended to be a collection of tutorials that I simply copy.

For each topic, I want to understand:

1. **What is it?**
2. **Why does it exist?**
3. **How does it work?**
4. **When should I use it?**
5. **What are its limitations and trade-offs?**
6. **Can I implement it myself?**
7. **Can I explain it without looking at the answer?**

Whenever possible, I will implement concepts myself rather than immediately reaching for a library or framework.

---

## 🤖 My Approach to AI

AI is allowed in this repository.

However, AI should be a **teacher, reviewer, and debugging partner — not the person doing the work for me.**

I may use AI to:

* Explain difficult concepts
* Give hints when I am stuck
* Review my implementation
* Help me understand an error
* Suggest better approaches
* Challenge my understanding
* Provide documentation or learning resources

I want to avoid:

* Copying entire solutions without understanding them
* Asking AI to build everything for me
* Blindly accepting generated code
* Using AI before attempting a problem myself
* Building projects that I cannot explain

### The Rule

> **Try first. Think first. Build first. Ask AI second.**

The objective is to develop my own engineering ability, not my ability to write prompts.

## 💡 Why "From Scratch"?

"From Scratch" does not mean reinventing everything.

It means going back far enough that I understand the foundations instead of continuously building on top of gaps in my knowledge.

Frameworks change.

Libraries change.

AI tools change.

Programming fundamentals remain.

I want to build a foundation strong enough that learning new technologies becomes much easier.

## 🏁 End Goal

By the end of this journey, I want to become a developer who:

* Understands the fundamentals deeply
